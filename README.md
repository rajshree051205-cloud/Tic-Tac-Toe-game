# Tic Tac Toe Game 🎮

A responsive and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features
- Two-player gameplay (X vs O)
- Win and draw detection
- Reset game functionality
- Clean and user-friendly interface
- Responsive design
- Interactive game board

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Project Purpose
This project was created to strengthen frontend development skills by applying HTML, CSS, and JavaScript concepts in a fun and practical way.

## What I Learned
- DOM manipulation
- Event handling
- Game logic implementation
- Responsive design
- UI styling and layout

## Future Improvements
- Add AI / Single-player mode
- Score tracking system
- Sound effects
- Improved animations
- Enhanced UI design

## How to Run
1. Download or clone the repository
2. Open the project folder
3. Run `build.html` in your browser
